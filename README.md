# Caelestia Arch Linux Environment

> **Caelestia** — это кастомная, минималистичная и современная сборка графического окружения на базе **Hyprland** для Arch Linux.

## 🚀 Быстрая установка

Вы можете развернуть всю систему одной командой, клонировав репозиторий:

```bash
git clone [https://github.com/Maksim426/my-dots.git](https://github.com/Maksim426/my-dots.git)
cd my-dots
sudo ./install.sh
```

## 🛠 Использование глобальной команды

После первой установки в системе автоматически регистрируется утилита **`Caelestia-save`**. Вы можете использовать её для быстрого обновления и применения конфигов в любое время:

```bash
Caelestia-save
```

## 📦 Что входит в сборку
- Оконный менеджер **Hyprland** (с автоматическими фиксами для виртуальных машин)
- Настроенный терминал, панели и темы оформления
- Автоматическая установка официальных пакетов и AUR-утилит
